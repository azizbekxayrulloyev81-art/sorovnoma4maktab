# 4-Maktab Diagnostika va Kasbga Yo'naltirish Portali

Ushbu portal 4-sonli umumiy o'rta ta'lim maktabining 5–11-sinf o'quvchilari uchun psixologik diagnostika, kasbiy qiziqishlar xaritasi va tahlillarini yuritish uchun yaratilgan.

## Asosiy xususiyatlar:
- **5–11-sinflar (A, B, V, G, D)** uchun to'liq moslashtirilgan.
- **Google Sheets bilan ikki tomonlama integratsiya**: yangi natijalarni jadvaldan avtomatik yuklab olish va yangi topshirilgan anketalarni real vaqtda Google Sheets'ga yuborish.
- **Admin paneli**: tahlil, sinf pasportlari, filtrlar va A4/Excel formatida hisobotlarni yuklab olish.
- **Sinf rahbarlari va o'qituvchilar kabineti**.

## Ishga tushirish:
```bash
pip install -r requirements.txt
python app.py
```
yoki Windows'da `run.bat` faylini ikki marta bosing.
